# ALERTA FAUNA: Aventura pelo Cerrado

Jogo de plataforma 2D em Pixel Art estilo Super Mario desenvolvido em HTML5, CSS3 e JavaScript (Canvas API), hospedável gratuitamente no GitHub Pages.

## Estrutura do Projeto

```text
alerta-fauna/
├── index.html
├── README.md
└── assets/
    ├── cerrado.png
    ├── lobo.png
    ├── npc.jpg
    └── seed.png
```

## Como Executar Localmente

1. Extraia o arquivo `alerta-fauna-github.zip`.
2. Abra o arquivo `index.html` diretamente no navegador (ou utilize uma extensão como *Live Server* no VS Code).

## Como Publicar no GitHub Pages

1. Crie um novo repositório público no GitHub (ex.: `alerta-fauna`).
2. Clique em **uploading an existing file** e envie o conteúdo da pasta `alerta-fauna` (`index.html`, `README.md` e a pasta `assets/`).
3. Acesse **Settings > Pages** no repositório.
4. Em **Source / Branch**, selecione `main` e `/ (root)`, depois clique em **Save**.
5. O jogo ficará disponível no endereço `https://seu-usuario.github.io/alerta-fauna/`.
